# Change Log

All notable changes to the "scope-gopher" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [0.0.2]

- Added the Scope Gopher logo as the Marketplace extension icon.

## [0.0.1]

- Added Go declaration highlighting for exported and unexported declarations.
- Added optional inlay hints that label declarations as exported or unexported.
- Used document symbols from the official Go extension and `gopls` to locate declarations.
- Limited default marking to functions and methods.
- Added settings for enabling highlighting, customizing exported and unexported colors, enabling inlay hints, customizing inlay hint labels, and choosing enabled declaration kinds.
- Supported configurable declaration kinds for functions, methods, interface methods, structs, interfaces, types, fields, variables, and constants.
- Added documentation for Scope Gopher behavior, configuration, requirements, and product language.
